# الإحسان — لتحفيظ القرآن الكريم

تطبيق لمحفّظات حلقات التحفيظ: الطالبات، تسجيل التسميع (حفظ جديد، مراجعة، اختبار)، خريطة الأجزاء، التذكيرات، والتقارير الشهرية (Excel وPDF وواتساب).

- يعمل **بدون إنترنت** بعد أول فتح (تطبيق ويب PWA يُثبَّت على شاشة الجوال).
- البيانات محفوظة **على الجهاز** (IndexedDB)، والنسخ الاحتياطي بملف يُحفظ على Google Drive من زر المشاركة.
- لا يحتاج خادماً ولا قاعدة بيانات: ملفات ثابتة فقط داخل مجلد `app/`.

## التشغيل محلياً

```bash
npm install
npm run vendor   # ينسخ الخطوط ومكتبة Excel إلى app/vendor
npm start        # http://localhost:5300
```

## النشر (GitHub Pages)

الرابط: **https://mohammed131207.github.io/al-ihsan/**

الموقع يُنشر من فرع `gh-pages` الذي يحتوي مجلد `app/` فقط. بعد أي تعديل:

1. غيّري `VERSION` في `app/sw.js` (مثلاً `halaqa-v4`) حتى تصل التحديثات للأجهزة.
2. احفظي التعديل في `main` ثم انشري:

```bash
npm run deploy
```

## الملفات

| الملف | الوظيفة |
|---|---|
| `app/js/quran.js` | السور والآيات وبدايات الأجزاء وحساب الأوجه التقريبي |
| `app/js/db.js` | التخزين المحلي |
| `app/js/logic.js` | التواريخ، حالة الطالبة، الملخص الشهري |
| `app/js/export.js` | Excel، رسائل واتساب، ملف النسخة الاحتياطية |
| `app/js/import.js` | استيراد الطالبات من Excel/CSV (يتعرّف على الأعمدة من عناوينها) |
| `samples/` | نموذج ملف Excel للاستيراد (أسماء وهمية) |
| `app/js/app.js` | الشاشات والتنقل |
| `app/sw.js` | العمل بدون إنترنت |

## الخصوصية

لا تُرسَل أي بيانات طالبات إلى أي خادم. هذا المستودع فيه كود التطبيق فقط، والبيانات تبقى على جهاز كل محفّظة.
